StreamReceive

The StreamReceive object is used to get and set received stream settings for the DM NVX device.

Syntax

  • HTTP Methods: GET, POST
  • Base URI: /Device/StreamReceive/

Properties

Property Name Parent Path Version Description Type Methods Validation Rules

Streams /Device/StreamReceive/ 2.0.0 A collection of streams on the device. Object Collection GET, POST N/A
