AudioVideoInputOutput

The AudioVideoInputOutput object is used to get and set data for A/V inputs and outputs on the DM NVX device.

Syntax

  • HTTP Methods: GET, POST

    • NOTE: ApplyEdid, DeleteEdid, and UploadEdid are write‑only properties and do not support the GET method.

  • Base URI: /Device/AudioVideoInputOutput/
