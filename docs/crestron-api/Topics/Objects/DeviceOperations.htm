DeviceOperations

The DeviceOperations object is used to get and set data for various device operations for the DM NVX device.

NOTE: Prior to issuing a FirmwareUpgrade POST request, ensure that the firmware file has been loaded to the device at the path specified within the POST request body. The POST request body should be formatted as multipart/form-data.

Syntax

  • HTTP Methods: GET, POST
  • Base URI: /Device/DeviceOperations/

Example JSON

The following example JSON uses the current object version (2.7.0).

Copy 
{
   "Device":{
      "DeviceOperations":{
         "FirmwareUpgrade":"",
         "FirmwareUpgradeType":"USB",
         "FirmwareUpgradePath":"Path",
         "GetXpanel: "Installer",
         "Reboot":true,
         "Restore":true,
         "Reset":true,
         "RestartWebServer": false,
         "EnterSetup":false,
         "ExitSetup": true,
         "EnterStandby":false,
         "ExitStandby":false,
         "GenerateLogs":"logs_Ipaddress_yyyy.MM.DD_HH.MM.SS",
         "SaveEdidFile" : "Output1", 
         "ProjectType": "OOTB",    
         "UploadProject":"",
         "UpgradeStatus":"Firmware Upgrade Rebooting",
         "ProgressPercentage" : 50,
         "SystemUpgrade": 
          {
             "TotalWaitingTime": 480
          }
         "Version":"2.7.0"
      }
   }
}
